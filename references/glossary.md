# 核心术语

| 术语 | 小白解释 | 需要注意 |
| --- | --- | --- |
| VPS | 放在数据中心、可远程管理的一台虚拟服务器 | 买到 VPS 不等于买到固定代理出口 |
| 域名 | 给 IP 地址使用的可读名称 | 同一名称可能同时返回 IPv4 和 IPv6 |
| DNS | 把域名查询成地址的服务 | 本机、代理和 VPS 可能使用不同 DNS |
| 端口 | 同一地址上区分服务的“门牌号” | TCP 端口和 UDP 端口是两套空间 |
| 入站 | 流量进入 VPS 时使用的协议、地址和端口 | VLESS Reality 和 HY2 是不同入口形态 |
| 出站 | 流量离开代理内核后采用的路径 | 可以是 VPS 原生出口或上游 SOCKS/HTTP 代理 |
| 路由 | 决定数据下一步从哪个接口或出口离开 | 系统路由、策略路由和 Xray 路由不是同一层 |
| TUN | 客户端创建的虚拟网卡，用来接管更多系统流量 | 路由或 IPv6 配置错误时可能绕过或形成访问回路 |
| 双栈 | 同时具备 IPv4 和 IPv6 | 双栈不保证两条路径质量相同 |
| CGNAT | 多名用户共享运营商公网 IPv4 的地址转换 | 会改变连接映射，但不能仅凭断连就断定发生了 CGNAT 切换 |
| TLS | 保护连接并验证服务身份的加密层 | 证书、域名、SNI、时间错误都可能造成握手失败 |
| ASN | 互联网路由中表示一个网络管理实体的编号 | ASN 标签说明地址归属，不能证明数据实际走过的全部线路 |
| traceroute | 通过逐步增加数据包生存时间观察部分中间设备 | 跳点可隐藏、变化或与真实应用流量不同 |
| 丢包 | 探测数据没有在期限内返回 | 路由器可能只限制探测包，不能只凭中间跳丢包判断业务故障 |
| 节点 | 客户端里可以选中的一条线路，包含地址、端口、协议和凭据 | 同一个应用里的两个节点通常共用一个进程，换节点不等于换到了独立的控制通道 |
| 订阅 | 一个链接，客户端定期从它下载最新的节点列表 | 更新订阅会用远端内容覆盖本地列表，可能悄悄改掉或删掉你正在使用的那一条 |
| 机场 | 别人搭好并按期出售节点使用权的服务 | 你只是使用者，没有服务器权限，出问题时能改的只有客户端这一侧 |
| 系统代理 vs TUN | 系统代理是每个程序自愿去读的一项设置；TUN 是虚拟网卡，在路由层直接接管流量 | 不读代理设置的程序只有 TUN 能接管，所以 TUN 出问题像整机断网，系统代理出问题只影响部分程序 |
| Xray | 跑在 VPS 上的代理内核，负责接收连接、按规则分流再转发出去 | 配置语法通过不代表节点可用，改完必须重载进程并真正连一次才算验证 |
| 3x-ui（面板） | 一个网页后台，用来管理 Xray 的节点、用户和流量统计 | 面板和内核是两个程序，面板能打开不代表节点能用，面板显示的在线数也不是连通性证据 |
| VLESS | 一种轻量的入站协议，只负责识别用户和转发，本身不加密 | 安全性完全来自外层的 TLS 或 Reality，且协议名相同但传输方式（TCP、gRPC、WebSocket）不同就连不上 |
| UUID（客户端凭据） | 一串固定格式的字符，服务端靠它认出你是哪个用户 | 它的作用等同于密码，泄露即可被他人直接使用，不得出现在报告、截图、回执或工单里 |
| Reality | 一种伪装方式，让连接在外部看起来像在访问某个真实的大网站 | 借用域名、公私钥和服务端时间必须严格一致，任何一项对不上通常只表现为连不上，不会给出明确原因 |
| SNI | TLS 握手时以明文携带的目标域名 | 它在加密开始之前发送，路径上的设备能看到；Reality 里填错 SNI 会让伪装失效或握手失败 |
| Hysteria2（HY2） | 基于 UDP 的入站协议，用自己的拥塞控制在丢包线路上取得更高速度 | 走 UDP，容易被运营商限速或整段丢弃；TCP 节点正常不能推断 HY2 正常，必须按协议单独测 |
| QUIC/UDP | 建立在 UDP 之上的新一代传输方式，HY2 等协议都用它 | 很多网络对 UDP 的 NAT 超时、限速和封锁策略与 TCP 完全不同，测试必须分协议进行 |
| MTU | 一条链路上允许通过的单个数据包最大长度 | 数值不合适时症状很怪：小请求正常，大文件或 TLS 握手卡死，容易被误判成服务器故障 |
| 分流规则 | 决定哪些域名或地址走代理、哪些直连、哪些拒绝的规则表 | 规则按顺序匹配，先命中的先生效；顺序写错会让本该走代理的流量直接漏到直连出口 |
| 落地/中转 | 中转机接收你的连接，再转给落地机，由落地机去访问目标站 | 外部看到的出口 IP 属于落地机，只看出口 IP 会完全漏掉链路中间的中转机 |
| SOCKS/HTTP 上游 | 代理内核把流量再交给另一个代理服务，由它去访问目标 | 上游内部的路径无法观察；上游认证失败常表现为节点连得上但网页打不开 |
