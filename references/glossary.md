# 核心术语

| 术语 | 小白解释 | 需要注意 |
| --- | --- | --- |
| VPS | 放在数据中心、可远程管理的一台虚拟服务器 | 买到 VPS 不等于买到固定代理出口 |
| 域名 | 给 IP 地址使用的可读名称 | 同一名称可能同时返回 IPv4 和 IPv6 |
| DNS | 把域名查询成地址的服务 | 本机、代理和 VPS 可能使用不同 DNS |
| 端口 | 同一地址上区分服务的“门牌号” | TCP 端口和 UDP 端口是两套空间 |
| 入站 | 流量进入 VPS 时使用的协议、地址和端口 | VLESS Reality 和 HY2 是不同入口形态 |
| 出站 | 流量离开代理内核后采用的路径 | 可以是 VPS 原生出口或上游 SOCKS/HTTP 代理 |
| 路由 | 决定数据下一步从哪个接口或出口离开 | 系统路由、策略路由和 Xray 路由不是同一层 |
| TUN | 客户端创建的虚拟网卡，用来接管更多系统流量 | 路由或 IPv6 配置错误时可能绕过或形成访问回路 |
| 双栈 | 同时具备 IPv4 和 IPv6 | 双栈不保证两条路径质量相同 |
| CGNAT | 多名用户共享运营商公网 IPv4 的地址转换 | 会改变连接映射，但不能仅凭断连就断定发生了 CGNAT 切换 |
| TLS | 保护连接并验证服务身份的加密层 | 证书、域名、SNI、时间错误都可能造成握手失败 |
| ASN | 互联网路由中表示一个网络管理实体的编号 | ASN 标签说明地址归属，不能证明数据实际走过的全部线路 |
| traceroute | 通过逐步增加数据包生存时间观察部分中间设备 | 跳点可隐藏、变化或与真实应用流量不同 |
| 丢包 | 探测数据没有在期限内返回 | 路由器可能只限制探测包，不能只凭中间跳丢包判断业务故障 |
