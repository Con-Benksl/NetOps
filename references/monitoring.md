# 本地监控设计与发布边界

## 本版本可以做什么

- `monitor install --dry-run` 只生成不可执行的调度审查材料；非 dry-run 无条件拒绝。
- `monitor remove --dry-run` 只生成移除审查材料。未通过本地文件所有权与完整性核对时，不输出可复制的调度命令；即使通过，也明确标记命令不可执行。
- `monitor status` 只检查规范路径下已有文件、权限、生命周期标记和 SHA-256 清单，不调用 systemd、launchd 或 Task Scheduler，也不证明真实任务存在、身份匹配或正在运行。
- 所有入口（包括模块内以下划线命名的旧实现）都在调度器和文件写入前拒绝。`--authorized`、环境变量或隐藏参数不能启用生命周期执行。

安装 dry-run 为了让审核者核对目标，会在 `plan.config.target.host` 和配置文件草案中显示目标。因此 stdout 不是脱敏支持包，不应复制到工单、聊天或公开仓库。系统级 Linux 计划还会只读核对解释器、入口和目录信任链；不满足 root 控制条件时标为 `blocked`，不得复制其中命令。

## 兼容采样

隐藏的 `monitor sample` 仅用于早期兼容版本已经正确配置的本地状态，不是新的安装入口。运行前必须同时满足：配置和状态使用当前平台/作用域的规范绝对路径，POSIX 配置/标记/清单为当前作用域所有且没有组或其他用户权限，状态标记为 active，清单哈希与所有受管文件一致。任一条件不满足都会在网络探测前返回固定错误码。

兼容采样的设计参数为：每 60 秒轻量检查，每 15 分钟增加本机只读检查；连续失败 3 次后最多进行 10 分钟、每 5 秒一次的短时增强采样。它不抓包、不运行 traceroute、信誉查询、精选外部工具或带宽测试。快照保留 7 天或 200 MB，以先达到者为准；文件数、目录项、单文件和状态文件也有硬上限。每次写入前后都先执行保留检查，超过边界时失败并返回真实状态，不报告已经被删除的路径。

## 长期保存的数据

允许：时间、匿名运行/观察外键、受控探针与区段名称、明确观察点、置信度、限制、地址族、连接耗时等有限数值指标、成功/失败/未知、资源数值、命令是否可用及返回码。

禁止：探测目标、IP、域名、设备主机名、原始路由/DNS/命令输出、数据包内容、节点链接、代理密码、私钥、Cookie、Authorization 头和完整应用请求。

目标只存在于本机私有配置和 install dry-run 审查输出，不进入 snapshot、monitor-state 或调度日志。采样异常只输出固定错误码。清理仅接受规范绝对状态目录、active 标记、私有权限和匹配清单；相对路径、普通文档目录、符号链接、junction、硬链接控制文件和不受管 JSON 都会拒绝。

## 尚未发布的调度器设计

审查材料描述 Linux systemd service/timer、macOS per-user LaunchAgent 和 Windows Task Scheduler，但本版本不安装、查询、停止或删除它们。旧事务实现保留在不可达代码中仅供对抗审查；调度器身份绑定、drop-in/同名任务所有权、崩溃恢复和跨平台实机验证完成之前不得移除 release gate。
