# 目标网站仅在某个出口拒绝

## 参数化环境

- 直连或出口 A：目标可访问
- 上游出口 B：目标超时、拒绝或支付流程失败
- 其他网站：大多正常

## 诊断

这组对照把问题范围缩小到出口 B 之后的链路、DNS、目标端口支持、IP 分类、WAF 或账号风控。它不能单独证明是代理供应商封端口，也不能证明是目标网站封 IP。

依次比较 DNS 答案、TCP/TLS、HTTP 状态、目标端口、IPv4/IPv6 和相同出口下的多个目标。支付失败还要与账号、Cookie、地区一致性和登录风险分开验证。
