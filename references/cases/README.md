# Case library / 通用案例

## English

Cases are worked examples, not Skills or hard-coded diagnosis rules. Each case
shows how to narrow a fault with declared environment facts and evidence.

A case must include:

- a parameterized environment;
- the reported symptom;
- a comparison or control observation;
- evidence for and against each explanation;
- the fault domain the evidence can support;
- conclusions that cannot be generalized from the case;
- one recommended next step.

Cases must not contain real IP addresses, domains, node links, UUIDs,
credentials, contacts, or account identifiers.

## 简体中文

案例不是 Skill，也不是硬编码诊断规则。每个案例只示范一件事：怎样用声明过的
环境事实和证据缩小故障范围。

一份案例必须写清楚：

- 参数化环境；
- 用户看到的现象；
- 对照测试；
- 支持和反对每个解释的证据；
- 现有证据能确认的故障范围；
- 不能从这份案例推广出去的结论；
- 一个推荐下一步。

案例不得包含真实 IP、域名、节点链接、UUID、凭据、联系人或账号标识。
